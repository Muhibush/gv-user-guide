Profile Page

Access your profile and account settings.

Access: Tap "Profile" in the bottom navigation

Available Options:

  • Profile Detail
  • Trainers
  • Journal Notes
  • FAQ
  • Change Password
  • Device Sessions
  • Logout

💡 The profile page is your hub for account management.

Profile Detail

View and manage your personal information.

Information Displayed:

  • Name
  • Phone Number
  • Email
  • City

Actions:

  • Edit profile information
  • Delete account (if needed)

📝 Account deletion is permanent and cannot be undone.

Trainers List

Browse available breathing instructors.

Features:

  • Search trainers by name
  • View trainer profiles
  • See trainer specializations

Action: Tap on a trainer to view their profile

💡 Each trainer specializes in different breathing techniques.

Trainer Profile

View detailed information about a specific trainer.

Information Displayed:

  • Trainer photo
  • Name and title
  • Specialization
  • Overview and experience

Action: Contact trainer via WhatsApp for questions

💡 Trainers can provide personalized guidance for your practice.

FAQ

Find answers to frequently asked questions.

Features:

  • Search questions
  • Filter by course type
  • Expandable answers

Common Topics:

  • Course structure
  • Payment methods
  • Prerequisites
  • Refund policy

💡 Check FAQ before contacting support for quick answers.

Change Password

Update your account password for security.

Fields:

  • Current Password
  • New Password
  • Confirm New Password

Password Requirements:

  • One uppercase letter
  • One lowercase character
  • 8 characters minimum
  • One number

📝 Use a strong, unique password for your account.

Device Sessions

Manage devices logged into your account.

Information Displayed:

  • Device name
  • Sign-in date
  • Current device indicator

Security: Review and revoke access for unrecognized devices

💡 Regularly check device sessions for account security.
