Admin Dashboard Login

Access the admin dashboard to manage payments.

URL: staging-dashboard-gv.muhibdev.biz.id/login

Step 1: Enter admin email address

Step 2: Enter admin password

Step 3: Tap "Sign in" to access dashboard

💡 Admin credentials are separate from user accounts.

2

Payment Status Page

View all user payments and their status.

Access: Navigate to Payments → User Payment Status

Table Columns:

  • User Detail (name, email)
  • Sending Method
  • Bought Items
  • Total Payments
  • Status (Pending/Paid/Expired)
  • Action (View details)

💡 Use the search box to find specific users by email.

3

Search for User

Find specific user payments by email.

Step 1: Locate the search box at the top

Step 2: Enter user email address

Step 3: View filtered results showing only that user's payments

📝 Search is real-time and filters as you type.

4 / 5
4

Payment Detail Dialog

View detailed information about a specific payment.

Information Displayed:

  • Invoice number
  • Status (Pending)
  • Date and time
  • Payment method
  • Course details and pricing
  • Bank information
  • User details

Actions:

  • "Confirm Payment" - Approve payment
  • "Close" - Return to list

📝 Payment approval is irreversible.

5 / 5
5

Payment Approved

Payment status updated to "Paid".

Step 1: Click "Confirm Payment" in the detail dialog

Step 2: Confirm the action in the popup

Step 3: Status changes from "Pending" to "Paid"

💡 The user's course access is unlocked immediately after approval.
