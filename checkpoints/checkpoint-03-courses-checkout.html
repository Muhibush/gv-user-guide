Courses Listing

Browse available breathing courses and workshops.

Access: Tap "Courses" in the bottom navigation

Features:

  • View all available courses
  • Filter by course type
  • See course details and pricing
  • Check availability and schedules

💡 Course availability depends on your location and schedule.

2

Course Details

View detailed information about a specific course.

Information Displayed:

  • Course name and description
  • Trainer information
  • Date, time, and location
  • Pricing details
  • Course overview and requirements

Action: Tap "Join now" to proceed to checkout

💡 Review all course details before proceeding to payment.

3 / 4
3

Checkout Page

Complete your course purchase with secure payment.

Step 1: Review order summary (course name, price)

Step 2: Apply promo code if available (optional)

Step 3: Select payment method:

  • Payment Gateway (card/e-wallet)
  • QRIS (QR code payment)

Step 4: Tap "Pay Now" to complete purchase

📝 Payment Gateway auto-completes in staging environment.
